# OpenFDTD_read_ofdfile
---
### abstract
This program reads the out.ofd file generated by OpenFDTD(https://ss023804.stars.ne.jp/OpenFDTD/index.html), calculates the electric field strength from the complex electric field vector, and displays it.

![ex01](./fig/ex01.jpg)

### Environment construction
```code
$ uv venv  
$ source .venv/bin/activate  
(OpenFDTD_read_ofdFile) $ uv pip install -r requirements.txt  
```
### How to execute
```code
(OpenFDTD_read_ofdFile) $ python maindisp.py
```
### Description of each file
***main code***  
maindisp.py: Read the data file and display the data. Read only ofd.out.  
  
***sub code***  
ReadOutData.py: read ofd.out.  
Planewave_t.py: A class to hold planewave parameters.  
cal_planewave.py: calculates the total field. ofd.out file  only contains scattered field data, so it's necessary to find the total field.  
cal_Intensity.py: calculates the electric field strength.  
NA.py: Find the index of a complex field.  
display_v2.py: display data.  

***data file***  
ofd.out: The output file from openfdtd. Read this file and display the data.  

***etc***  
requirements.txt: Required Python libraries
